# Отдельный булевый движок для цифровой логики

Модуль «Цифровая логика» (И/ИЛИ/НЕ, триггеры) решено строить на отдельном событийном булевом движке со строгими сигналами 0/1, а не моделировать логические элементы в общем аналоговом симуляторе. Смешение аналоговых и цифровых сигналов в одном движке (как в реальном SPICE) — несоразмерный объём работы для учебного сайта и не несёт учебной пользы на этом уровне.

## Considered Options

- Единый аналоговый симулятор для всего — отвергнуто: смешение доменов (analog + digital) требует уровня зрелого SPICE; учебные задачи М3 полностью покрываются таблицами истинности.

## Consequences

- У Модуля «Цифровая логика» свой холст с логическими элементами, ключами, тактовым генератором и индикаторами; проверка — по таблицам истинности.
- Аналоговый Симулятор остаётся единственным движком для М1/М2/М4; общий код переиспользуется только на уровне Холста и UI.
