# 21: М4 — Задания: RC-фильтр и выпрямитель

**What to build:** Схема-задания Модуля «Переменный ток». RC-фильтр: амплитудно-частотная характеристика строится свипом фазоров по частоте, график АЧХ с курсором показывает, где фильтр режет. Выпрямитель на диоде: переходный режим, график напряжения во времени до и после диода. Условия-измерения — по амплитуде на заданной частоте и по форме выпрямленного сигнала.

**Blocked by:** 20 (фазорный режим)

**Status:** ready-for-agent

- [ ] АЧХ строится свипом фазоров, график с курсором показывает амплитуду на выбранной частоте
- [ ] Выпрямитель считается в переходном режиме, график показывает сигнал до и после диода
- [ ] Задание «фильтр, ослабляющий частоту F не менее чем в N раз» проверяется по расчёту (тест)
- [ ] Задание на выпрямитель проверяется по амплитуде/форме выходного сигнала (тест)
- [ ] Оба типа Заданий проходят полный цикл: сборка → «Проверить» → Диагноз/Разбор
