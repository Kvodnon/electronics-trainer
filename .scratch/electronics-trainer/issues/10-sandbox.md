# 10: Песочница

**What to build:** Свободный режим для экспериментов: вход из главного меню, доступен с началом Курса. Без условий и проверки — только Палитра (все Компоненты, открытые текущим Прогрессом), Симулятор, Мультиметр и живое поведение схем. ## Comments

Implemented in feat commit (TDD: домен → хранилище → UI; правки по code-review в рефактор-коммите; 253 теста, было 223) + ручная проверка в браузере. Layout:

- `src/domain/course.ts` — `modulePaletteOf` (объединение Палитр Схема-заданий Модуля; отдельного источника правды нет — Палитра объявляется в контенте Заданий) и `sandboxPaletteOf` (объединение Палитр разблокированных Модулей в порядке Курса, без дублей). Палитра Песочницы растёт с прохождением Модулей автоматически: тикеты 13–16 добавят виды Компонентов в Задания М2 — Песочница откроет их без переделки.
- `src/domain/sandbox.ts` — `SavedCircuit { id, name, canvas }`; чистые `upsertCircuit` (занятое имя перезаписывает схему с тем же id и местом, новое — в конец; id вида s1, s2… по максимуму), `removeCircuit` (нет такой — тот же список, то же сравнение) и `isValidCircuitName` (непусто после обрезки — единственное место, где формулируется правило имени).
- `src/domain/canvas.ts` — действие `canvas-loaded`: загрузка снимка начинает новую историю (undo не возвращает прежний черновик — загрузка трактуется как новый сеанс правки). `ComponentKind` теперь выводится из константы `componentKinds` (`as const` + тип из неё) — список и union не могут разойтись; `isComponentKind` — для проверок данных из хранилища.
- `src/storage/sandboxStorage.ts` — ключ `electronics-trainer.sandbox.v1`, тот же localStorage, что у Прогресса. Беда верхнего уровня (мусор, чужая структура) — «схем нет»; некорректная схема внутри списка отбрасывается по одной, уцелевшие читаемы: проверяются id/имя, вид и поворот Компонентов, конечность номиналов, существование Компонента на конце каждого Провода и номер вывода.
- Общая кинематика вынесена из экрана Схема-задания: `src/components/canvas/liveCircuit.ts` — хуки `useLiveCircuit` (живое решение Симулятора + показания) и `useMultimeter` (включённость, режим, щупы, показание; возвращает готовый пропс `gestures` для Холста), `src/components/canvas/ToolbarControls.tsx` — `MultimeterControls` и `StandardControls`. `CircuitTaskScreen` переведён на них без изменения поведения (все 33 его теста прошли без правок); Песочница получает тот же Симулятор, Мультиметр и живое поведение — но без «Проверить», оверлея и вердиктов.
- `src/components/SandboxScreen.tsx` — заголовок с «← К Курсу», Холст с Палитрой по Прогрессу и панель «Мои схемы»: поле имени (кнопка сохранения неактивна при пустом имени), список сохранённых схем с «Загрузить»/«Удалить» (aria-label с именем). Перезапись под тем же именем показана в списке единственной записью. `src/components/CourseScreen.tsx` — карточка входа «Песочница → Открыть» над списком Модулей. `App` держит схемы в состоянии и сохраняет их эффектом, как Прогресс; палитра считается `sandboxPaletteOf(course, progress)` на каждый рендер.
- CSS: карточка входа, панель «Мои схемы», собственный стиль поля имени (без заимствования класса числового ввода).

Тесты (253): домен — рост Палитры после прохождения Модуля и устойчивый порядок без дублей (фикстура курса с различающимися Палитрами; реальный контент М2 пока повторяет Палитру М1 — она заглушка до тикетов 13–16); upsert (перезапись по имени, id не переиспользуются после удаления, чистота), удаление и правило имени; `canvas-loaded` (замена Холста, свежая история, обычная работа после). Хранилище — roundtrip без потерь (номиналы, повороты, Провода), затирание списка, мусор/чужая структура/поломанные схемы/неизвестный вид/чужой поворот/Провод в никуда, отказ хранилища при записи и чтении. Компонентные — Песочница без «Проверить» и оверлея, живое свечение и Мультиметр (8,99 В) работают сами; сохранение → сброс → загрузка без потерь (позиции, поворот, Провод, свечение сразу); перезапись имени; удаление; пустое имя. App — вход из главного меню, сохранение, «перезагрузка» (размонтирование + новый App), загрузка без потерь; выход «← К Курсу» Прогресс не трогает.

Code-review (Standards + Spec): исправлено — «свободный режим» в комментарии (запрещённая формулировка из Avoid-списка CONTEXT.md), правило имени из трёх мест в одно (`isValidCircuitName`), удаление схем из inline-фильтра в App в домен (`removeCircuit`), `ComponentKind` выводится из списка, а не дублирует union, поле имени со своим классом, «← К Модулям» → «← К Курсу» (Песочница открывается из главного меню), тест экрана использует `modulePaletteOf(module1)` вместо сырой константы. Оставлено осознанно: формат id `sN` с парсингом номера — в том же стиле, что внутренний `nextId` редьюсера Холста (c1/w1); тумблер ГОСТ/ANSI в Песочнице (переключатель — часть инструментов Холста, меняет только отрисовку); вынос хуков из Схема-задания — обеспечивающий рефакторинг под Песочницу, поведение накрыто прежними тестами.

Spec-решения, требующие подтверждения: (1) гранулярность Палитры — Модуль целиком: открыв Модуль, ученик получает всю его Палитру, включая Компоненты Экзамена, до того как дошёл до них («Палитра, растущая вместе с Модулями» из спеки — модульная гранулярность; внутри-модульная потребовала бы связки Прогресса с темами). (2) Загрузка сохранённой схемы молча заменяет текущий черновик (история отмены не спасает — это новый сеанс правки); «не потерять удачные эксперименты» закрывается самими сохранениями, диалог подтверждения не делался. (3) Черновик Холста между перезагрузками не сохраняется — критерий тикета («Схемы Песочницы … переживают перезагрузку») закрыт именованными сохранениями; если понадобится, это отдельное малое расширение хранилища.

Проверено вручную в браузере (IAB, vite dev): вход «Открыть» с экрана Курса; контур батарея–лампочка (два Провода) — лампочка светится без всякой «Проверить»; сохранение «Кольцо» легло в localStorage; настоящая перезагрузка страницы → «Кольцо» в списке → «Загрузить» → Компоненты, Провода и свечение на месте сразу. Замечание по автоматизации: программные клики в панели IAB не доставляются, проверка шла через evaluate — к приложению отношения не имеет.
