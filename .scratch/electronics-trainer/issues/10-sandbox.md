# 10: Песочница

**What to build:** Свободный режим для экспериментов: вход из главного меню, доступен с началом Курса. Без условий и проверки — только Палитра (все Компоненты, открытые текущим Прогрессом), Симулятор, Мультиметр и живое поведение схем. Ученик сохраняет несколько своих схем с именами, загружает и удаляет их; схемы живут в том же хранилище, что Прогресс, и переживают перезагрузку.

**Blocked by:** 08 (Мультиметр — часть Песочницы)

**Status:** ready-for-agent

- [ ] Песочница открывается из главного меню, Палитра отражает текущий Прогресс Курса
- [ ] Симуляция, Мультиметр и живое поведение работают без кнопки «Проверить»
- [ ] Сохранение, загрузка и удаление нескольких именованных схем
- [ ] Схемы Песочницы и Прогресс переживают перезагрузку страницы
- [ ] Тесты: палитра растёт после прохождения Модуля; сохранение/загрузка схемы без потерь
