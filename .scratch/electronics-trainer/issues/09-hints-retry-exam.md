# 09: Подсказки, повтор ошибок, Экзамен

**What to build:** Три механизма завершения Модуля. Лестница Подсказок во всех типах Заданий: первая ступень — наводящий вопрос, вторая — почти решение; готовый ответ не выдаётся. Задания, где ученик ошибся, возвращаются в конце Модуля, пока не будут решены. Экзамен — финальное Схема-задание Модуля, объединяющее его темы: закрыт, пока не пройдены все остальные Задания; его прохождение завершает Модуль и открывает следующий. В статистике Заданий помечается «решено с первой попытки».

**Blocked by:** 03 (редьюсер Курса и правила Модулей), 05 (Схема-задания, к которым применяются Подсказки)

**Status:** done

- [x] Задание, решённое не с первой попытки, попадает в очередь повтора в конце Модуля и не отпускает до решения
- [x] Экзамен закрыт, пока не закрыты все остальные Задания Модуля

## Comments

Implemented in feat commit (TDD: редьюсер → хранилище → UI-шов; правки по code-review в том же коммите; 223 теста, было 202). Layout:

- `src/domain/task.ts` — `TaskHints { question, almostSolution }`: лестница двух ступеней (ступень 1 — наводящий вопрос, ступень 2 — почти решение; готовый ответ не выдаётся — договорённость о контенте, см. ниже). Опциональное `hints` добавлено всем трём видам Заданий. `CircuitTask` получил `isExam` — Экзамен остаётся обычным Схема-заданием для `evaluate` и Холста, вся специфика (закрытие, метка) живёт в правилах Модуля и UI.
- `src/domain/course.ts` — «Решено с первой попытки» выводится из `CourseProgress.failedOnce` (словарь «провалено хотя бы раз до прохождения»): `solvedOnFirstAttemptOf` = пройдено и нет отметки о провале. Новое действие `attempt-failed` — неудачная проверка Схема-задания на месте: ставит только отметку о попытке, состояние Задания и очередь не меняет (ученик не выпускает из Схема-задания, менять очередь нечему); на пройденном — no-op, перезапись статистики невозможна. `task-returned-for-retry` (Вопросы, уход по «Дальше») теперь же ставит отметку — статистика Вопросов не потребовала изменений UI. `moduleProgressOf` считает `solvedOnFirstAttempt`. Экзамен: `isExamTask`/`examOf`/`isExamUnlocked` (все остальные Задания Модуля пройдены); `moduleTaskQueue` исключает закрытый Экзамен — он открывается последним, а его собственный повтор встаёт в конец очереди как у всех Заданий.
- Повтор ошибок (критерий 2) — механизм тикета 03 (`moduleTaskQueue`: не начатые вперёд, вернувшиеся в конец) сохранён без изменений и покрыт существующими тестами; новыми тестами закрыт и повтор Экзамена.
- `src/storage/progressStorage.ts` — `failedOnce` валидируется (только значения `true`); сохранения первой версии без `failedOnce` читаются, при загрузке нормализуются в «чистые» — статистика по Заданиям, пройденным до тикета 09, остаётся честной.
- `src/components/HintLadder.tsx` — новый компонент лестницы: ступени раскрываются по одной кнопками «Подсказка» → «Ещё подсказка», у ступеней подписи «наводящий вопрос» / «почти решение».
- Экраны: `QuestionScreen`/`NumericQuestionScreen` показывают лестницу до ответа (после ответа её место занимает Разбор); `CircuitTaskScreen` — пока Задание не решено вердиктом «Пройдено», и метка «Экзамен» вместо «Схема-задание» по `isExam`. `ModuleScreen`: `handleAnswer` синхронно диспетчит `attempt-failed` при неверной проверке Схема-задания; точки Заданий — ромб у Экзамена (пунктир и title «откроется после остальных Заданий», пока закрыт), фосфорный ореол у решённых с первой попыткой, подписи через `taskDotTitle`; `ModuleProgressLine` дополнен «· с первой попытки: N».
- CSS: панели подсказок (левый фосфорный акцент, моноширинные подписи ступеней), ромб/пунктир/ореол точек, окраска «с первой попытки».
- Контент: Подсказки добавлены всем существующим Заданиям М1/М2 (ступень 2 нигде не называет ответ). Экзамены-заглушки: `m1-exam` (закон Ома: контур батарея–выключатель–резистор–лампочка, ток через резистор 40–60 мА, лампочка горит) и `m2-exam` (моторчик крутится, ток 60–100 мА); оба решаются правкой номинала резистора, эквивалентные решения проходят по измерениям (ADR-0001). Тикет 12 заменит `m1-exam`, тикеты 13–16 — `m2-exam` полным контентом.

Тесты (223): домен — 6 на Экзамен (экзаменационное Схема-задание находится по `isExam`; закрыт, из очереди исключён; открыт последним при незавершённом Модуле; сдача завершает Модуль и открывает следующий — критерий «тест редьюсера»; повтор Экзамена держит его в очереди; чужой повтор очередь не меняет) и 7 на «первую попытку» (прятое прохождение; ошибка → прохождение; `attempt-failed` не меняет состояние и очередь, но ломает стату; no-op на пройденном; идемпотентность и чистота редьюсера; подсчёт по Модулю). Хранилище — legacy без `failedOnce`, битая `failedOnce`. Компонентные — подсказка по ступеням в Вопросе с выбором и числовом Вопросе (App) и в Схема-задании из настоящего контента М2 + метка Экзамена (CircuitTaskScreen); поток Экзамена М1: неудачная проверка (разомкнутый выключатель) сорвала «первую попытку», сдача завершила Модуль и открыла М2 (критерий 6 — повтор после ошибки — накрыт обновлённым тестом «Повтор ошибок внутри Модуля»); полный Курс через оба Экзамена; существующие потоки обновлены на модули из трёх Заданий.

Code-review (Standards + Spec): нарушений документированных стандартов нет; исправлено — мёртвый алиас в `progressStorage`, дублирование предиката Экзамена в тесте (использован доменный `isExamTask`), `withFailedOnce` → `markFailedOnce` (возвращает словарь, не Прогресс), вложенные тернарники подписей точек → `taskDotTitle`; в CONTEXT.md добавлен термин «Решено с первой попытки». Оставлено осознанно: двойной вызов `evaluate` при неверной проверке Схема-задания (чистая функция, схемы крошечные); «не решено» у трёх экранов сформулировано по-разному намеренно (Вопросы скрывают подсказку ответом, Схема-задание — вердиктом «Пройдено»).

Spec-решения, требующие подтверждения: (1) неудачная проверка Схема-задания считается попыткой и портит «первую попытку», но не возвращает Задание в очередь — «возврат в конец» для Схема-задания физически недостижим (из него нельзя уйти, не решив), держание на месте сильнее; retry-ветка редьюсера для Экзамена существует и протестирована, из UI недостижима. (2) `examOf` берёт первое `isExam`-Задание; позиция «Экзамен последним в `module.tasks`» — договорённость о контенте (текущий контент соблюдает). (3) «Текст не содержит готового ответа» проверен вручную по всем шести подсказкам; автоматическая проверка придёт с контент-линтером тикета 12.
