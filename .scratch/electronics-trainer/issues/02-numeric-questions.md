# 02: Числовые Вопросы

**What to build:** Второй тип Вопроса — числовой ввод («посчитай ток»). Ученик вводит ответ с запятой или точкой, с суффиксами единиц (мА, А, кОм, МОм, мВ, кВ) или без (тогда базовая единица: А, В, Ом). Проверка с допуском ±5% по умолчанию, Задание может задать свой допуск. После неверного ответа показывается пошаговое решение; после верного — подтверждающий Разбор.

**Blocked by:** 01 (экран Вопроса и домен-шов проверки)

**Status:** ready-for-agent

- [ ] «0,01» и «10мА» распознаются как одинаковый ответ
- [ ] Отсутствие суффикса трактуется как базовая единица (А, В, Ом)
- [ ] Неверный ввод (мусор, неизвестный суффикс) отклоняется с понятным сообщением, попытка не сжигается
- [ ] Юнит-тесты парсера: суффиксы, разделители, допуск, границы диапазона
- [ ] Неверный ответ → пошаговое решение показано; верный → подтверждающий Разбор
- [ ] Компонентный тест: ввод числа → вердикт → решение
