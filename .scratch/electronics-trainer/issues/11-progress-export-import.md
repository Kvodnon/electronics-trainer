# 11: Экспорт, импорт и сброс Прогресса

**What to build:** Управление данными: кнопка экспорта выгружает Прогресс и схемы Песочницы в JSON-файл; импорт восстанавливает их (например, в другом браузере или после переустановки системы); «начать заново» сбрасывает весь Прогресс после подтверждения. Некорректный файл импорта не ломает текущий Прогресс и объясняет, что не так.

**Blocked by:** 03 (Прогресс, который экспортируем)

**Status:** ready-for-agent

- [ ] Экспорт скачивает файл со всем Прогрессом и схемами Песочницы
- [ ] Импорт из файла, выгруженного этим же приложением, полностью восстанавливает состояние
- [ ] Импорт битого/чужого файла отклоняется с понятной ошибкой, текущий Прогресс не повреждается (тест)
- [ ] «Начать заново» очищает всё только после явного подтверждения
- [ ] Тесты валидации формата; компонентный тест кнопок экспорта/импорта
