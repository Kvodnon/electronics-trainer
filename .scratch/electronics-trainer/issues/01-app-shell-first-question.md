# 01: Каркас приложения и первый Вопрос (сквозной луч)

**What to build:** Статический сайт (Vite + React + TypeScript) с тёмной «лабораторной» темой и первый Вопрос, работающий от начала до конца: на экране Задание с выбором варианта, по клику вариант помечается верным или неверным, показываются Разборы — и к выбранному, и к каждому неверному варианту (с указанием ошибки мышления), затем переход дальше. Весь домен (оценивание Ответа) — чистый TypeScript без DOM, UI — тонкий слой над ним. Один демонстрационный Вопрос в данных.

**Blocked by:** None (can start immediately)
