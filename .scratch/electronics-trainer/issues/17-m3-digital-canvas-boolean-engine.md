# 17: М3 — цифровой Холст и булевый движок

**What to build:** Отдельный цифровой Холст по ADR-0002: событийный булевый движок со строгими сигналами 0/1, логические элементы И/ИЛИ/НЕ, кнопка, индикатор и тактовый генератор с регулируемой частотой. Состояние каждого входа и выхода видно в реальном времени, сигналы на Проводах отображаются уровнем. Свободная сборка: демо-схема собирается и живёт без аналогового Симулятора. Цифровые схемы живут в своём Холсте; с аналоговым Холстом общий только UI-слой.

**Blocked by:** 12 (принятая М1, зрелый UI Холста)

**Status:** ready-for-agent

- [ ] Булевый движок корректно распространяет сигналы в комбинационных схемах (тесты таблиц истинности элементов)
- [ ] Состояния всех входов/выходов элементов видны на схеме в реальном времени
- [ ] Кнопка переключает сигнал, индикатор показывает уровень
- [ ] Тактовый генератор тикает с регулируемой частотой
- [ ] Редьюсер цифрового Холста без DOM, протестирован (постановка, соединение, удаление)
