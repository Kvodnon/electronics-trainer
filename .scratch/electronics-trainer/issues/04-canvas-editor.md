# 04: Холст — редактор схем

**What to build:** Редактор схем для Схема-заданий: Палитра М1 (батарея, резистор, лампочка, выключатель, ключ, моторчик), перетаскивание Компонента на Холст, перемещение с сохранением Проводов, поворот, удаление Компонента вместе с его Проводами, рисование Провода между выводами (ортогональные сегменты, привязка к сетке), правка номиналов Компонентов, undo/redo. Рендер — SVG в ГОСТ. Проверки пока нет: Задание рендерится, схему можно собрать и сбросить.

## Comments

Implemented in commits 23e7bba + 68127ec (TDD на шве редьюсера Холста, затем правки по code-review). Layout:

- `src/domain/canvas.ts` — чистый TypeScript без DOM: модель `PlacedComponent` (вид из Палитры М1, позиция в узлах сетки 20, поворот 90°, номиналы: батарея — voltage, резистор/лампа/мотор — resistance, выключатель/ключ — closed) и `Wire` (соединение ссылками на выводы `PinRef`, а не координатами — поэтому не рвётся при перемещениях). Редьюсер `canvasReducer` с историей undo/redo в состоянии (`CanvasHistory`: past/present/future); идентификаторы назначает редьюсер (c1…/w1…); действия: постановка, перемещение, поворот, удаление (вместе с Проводами), правка номинала (поле только своего вида, конечное и положительное), Провод (без дубликатов и петель; несколько Проводов на выводе разрешены — параллельные ветви), удаление Провода, undo, redo, сброс. Хелперы: `suggestPlacementPosition` (клик по Палитре кладёт на первое свободное место построчным обходом), `defaultValuesOf`, `valueFieldOf`.
- `src/domain/canvasGeometry.ts` — чистая геометрия: сетка и границы Холста 800×560, `pinPointOf` (выводы на ±40 от центра, поворот по часовой), `routeWire` — ортогональная трассировка (выход 20 вдоль вывода, затем Г/Z-обход без возврата назад; вырожденные и коллинеарные сегменты схлопываются). Все точки — в узлах сетки.
- `src/components/canvas/CanvasSymbols.tsx` — символы ГОСТ для Палитры М1 (батарея с «+», резистор-прямоугольник, лампа с косым крестом, выключатель с подвижным плечом, ключ с приводом-кнопкой, мотор с «М»); подпись номинала через `formatQuantity` («9 В», «1 кОм», «замкнут»). Набор ANSI — тикет 07.
- `src/components/canvas/CanvasEditor.tsx` — жесты и отрисовка: клик по Палитре (и drag-and-drop из неё) ставит Компонент; перетаскивание мышью рисуется поверх состояния и фиксируется одним `component-moved`; клик по выводу тянет Провод (Esc — отмена); выбор Компонента/Провода открывает панель правки; клавиши R/«к»/Delete дублируют кнопки (не срабатывают при наборе в поле номинала). `CanvasSelectionPanel.tsx` — панель правки с формой номинала (запятая/точка и суффиксы через `parseQuantity`).
- `src/components/canvas/CircuitTaskScreen.tsx` — экран Схема-задания: условие + Палитра + Холст. `domain/task.ts` получил `CircuitTask` с палитрой Задания; `evaluate` для него честно бросает «проверка появится с Симулятором (тикет 05)».
- `src/content/m1.ts` — экспорт `module1Palette` (6 Компонентов М1); `m2.ts` — временная витрина Холста `m2-canvas-demo` (см. ниже), `ModuleScreen` ветит Схема-задания.
- Тесты: 22 редьюсер (каждое действие, no-op'ы тем же сравнением, undo/redo, сброс, границы, сериализация JSON + продолжение редактирования на восстановленном состоянии), 8 геометрия (выводы при поворотах, ортогональность/сетка маршрутов, прямые и Г/Z-случаи), 12 компонентных (все операции мышью через Testing Library, домен не мокается; для перетаскивания — fireEvent-тройка mousedown/mousemove/mouseup с замоканным `getBoundingClientRect`, т.к. jsdom не считает layout, а userEvent авто-отпускает кнопку между вызовами). 110 всего.

Проверено вручную в браузере (IAB): полный поток до Холста, постановка, Провода, перетаскивание с перетрассировкой («140,100 300,100 300,220 320,220» — соединение не порвалось), поворот (выводы уехали с поворотом, Провод перерисовался), номинал «4,5 В» через запятую, undo/redo/сброс; символы ГОСТ сверены по скриншоту. Замечания среды IAB (те же, что в тикете 03): отложенные коммиты состояния при программных сериях кликов, потеря физических событий на затемнённой панели, артефакты захвата скриншотов — состояние проверялось по DOM, жесты подтверждены до деградации панели.

Заметки для следующих тикетов:

- М2 с витриной `m2-canvas-demo` не завершается до тикета 05 (у Схема-задания нет проверки → нет «пройдено»); М1 проходима целиком, блокировка М2/демо-flow не страдает. Тикет 05 подключает `evaluate(CircuitTask, canvas)`, тикет 13 заменяет заглушку контентом.
