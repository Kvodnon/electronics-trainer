# 04: Холст — редактор схем

**What to build:** Редактор схем для Схема-заданий: Палитра М1 (батарея, резистор, лампочка, выключатель, ключ, моторчик), перетаскивание Компонента на Холст, перемещение с сохранением Проводов, поворот, удаление Компонента вместе с его Проводами, рисование Провода между выводами (ортогональные сегменты, привязка к сетке), правка номиналов Компонентов, undo/redo. Рендер — SVG в ГОСТ. Проверки пока нет: Задание рендерится, схему можно собрать и сбросить.

**Blocked by:** 01 (каркас приложения)

**Status:** ready-for-agent

- [ ] Все операции редактора работают мышью: поставить, переместить, повернуть, удалить, соединить, изменить номинал
- [ ] Провода перерисовываются при перемещении Компонентов, соединения не рвутся
- [ ] Undo/redo покрывает все действия редактора
- [ ] Редьюсер Холста — чистая функция без DOM, протестирована на каждое действие
- [ ] Состояние Холста сериализуется и восстанавливается без потерь (тест)
- [ ] Все Компоненты Палитры М1 рендерятся в ГОСТ
