# 08: Мультиметр

**What to build:** Режим измерений на Холсте: ученик включает Мультиметр, выбирает режим (напряжение или ток), прикладывает щупы к двум точкам схемы — видит напряжение между ними; измеряет ток выбранной ветви. Мультиметр доступен как свободный инструмент в любом Схема-задании, показания обновляются при любом изменении схемы.

**Blocked by:** 05 (Симулятор как источник показаний)

**Status:** ready-for-agent

- [ ] Щупы, приложенные к двум точкам, показывают напряжение между ними, совпадающее с расчётом Симулятора (тест)
- [ ] Ток ветви измеряется корректно, включая ветви после переключения выключателя
- [ ] Показания обновляются при изменении схемы без перезапуска режима
- [ ] Показания недоступны/обнуляются, пока цепь не решается (обрыв — честное «нет тока»)
- [ ] Компонентный тест: включить Мультиметр → приложить щупы → показание видно
