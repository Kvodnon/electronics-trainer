# Электроника с нуля (тренажёр)

Локальный сайт-тренажёр для одного пользователя, чтобы с нуля научиться электронике: линейный курс из модулей, вопросы с разборами и сборка схем на холсте с автоматической проверкой через симуляцию.

## Language

### Курс

**Тренажёр**:
Приложение целиком: курс, вопросы, холст для схем и проверка.
_Avoid_: сайт (слишком общо), платформа

**Курс**:
Линейная последовательность модулей; следующий модуль открывается после прохождения предыдущего.
_Avoid_: программа, трек

**Модуль**:
Самостоятельный этап курса (например, «Основы DC»), содержит Теорию, Вопросы и Схема-задания.
_Avoid_: уровень, глава

**Теория**:
Короткий обучающий экран перед вопросами темы: диаграммы и формулы, без интерактивных заданий. Обозначения компонентов показываются в двух стандартах рядом: ГОСТ/IEC и ANSI.
_Avoid_: урок, лекция

**Экзамен**:
Финальное Схема-задание Модуля, объединяющее его темы; открывается после закрытия всех остальных Заданий Модуля.
_Avoid_: контрольная, итоговый тест

**Прогресс**:
Состояние прохождения Курса учеником: какие Модули и Задания пройдены.
_Avoid_: сохранения, сейвы

### Задания и проверка

**Задание**:
Единица работы ученика внутри модуля; бывает двух видов: Вопрос и Схема-задание.
_Avoid_: упражнение, тест, задача

**Вопрос**:
Задание с ответом без сборки схемы: выбор варианта или числовой ввод.
_Avoid_: квиз

**Схема-задание**:
Задание, где ученик собирает схему из Компонентов на Холсте; проверяется Симулятором по измерениям, а не по совпадению с эталоном.
_Avoid_: практика, лабораторная

**Разбор**:
Объяснение, почему ответ или схема верны или неверны; обязательная часть каждого Задания. Для неверного варианта выбора — свой Разбор на каждый вариант.
_Avoid_: объяснение, фидбек, обратная связь

**Диагноз**:
Вердикт проверки Схема-задания: пройдено; работает, но не по условию; ошибка с указанием места на схеме.
_Avoid_: статус проверки

**Подсказка**:
Ступень помощи внутри Задания, не дающая готового ответа: сначала наводящий вопрос, затем почти решение.
_Avoid_: ответ, спойлер

**Решено с первой попытки**:
Статистика Задания в Прогрессе: пройдено без единой неудачной попытки до прохождения.
_Avoid_: идеально, без ошибок

**Мультиметр**:
Режим измерений на Холсте: щупы прикладываются к двум точкам (напряжение) или к ветви (ток).
_Avoid_: пробник, измеритель

### Холст

**Холст**:
Свободное рабочее поле Схема-задания: Компоненты перетаскиваются, соединяются Проводами.
_Avoid_: редактор, канвас

**Палитра**:
Набор Компонентов, доступных на Холсте; расширяется с прохождением Модулей.
_Avoid_: тулбар, панель деталей

**Песочница**:
Свободный режим без Заданий и проверки: открытая курсом Палитра, Симулятор, Мультиметр и сохранение собственных схем.
_Avoid_: свободный режим, песочница схем

**Компонент**:
Элемент схемы на Холсте (источник, резистор, светодиод…), имеет выводы для подключения Проводов.
_Avoid_: деталь, элемент

**Источник ~**:
Источник переменного напряжения на Холсте: настраиваются амплитуда и частота; первый источник задаёт частоту всей схемы.
_Avoid_: генератор (занят цифровым Компонентом М3), источник переменного тока, розетка

**Катушка**:
Компонент с индуктивностью: переменному току сопротивляется (X_L = 2πf·L), постоянный ток пропускает почти как провод.
_Avoid_: дроссель, соленоид, индуктивность (как имя Компонента)

**АЧХ**:
Амплитудно-частотная характеристика фильтра: кривая амплитуды на выходе по частоте, строится свипом фазоров по логарифмической сетке; курсор стоит на частоте источника ~.
_Avoid_: график частоты (расплывчато), Боде-диаграмма, ЛАЧХ

**Выпрямитель**:
Схема из диода и нагрузки: диод пропускает одну полуволну источника ~, и на нагрузке остаются пульсации одной полярности.
_Avoid_: блок питания (это следующая ступень с фильтром-конденсатором), преобразователь

**Провод**:
Соединение двух выводов Компонентов на Холсте.
_Avoid_: линия, связь

**Симулятор**:
Вычисляет токи и напряжения собранной схемы; на его показаниях строятся условия Схема-заданий и Диагнозы.
_Avoid_: чекер, валидатор
