# AGENTS.md

## Agent skills

### Issue tracker

Issues are tracked as local markdown files under `.scratch/<feature-slug>/`. See `docs/agents/issue-tracker.md`.

### Domain docs

Single-context: one `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.

## Code style

Identifiers (variables, functions, types, CSS classes) are written in English, using the domain glossary's English counterparts (`task`, `razbor`, `verdict`, `progress`…). Russian stays in comments, UI copy, and test descriptions only.
